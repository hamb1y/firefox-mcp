WebMCP Controller

Lets your own AI harness read and drive this Firefox. A small helper app, started by Firefox, serves MCP on your machine.

1. Install the helper app

Uninstall / other systems Windows: & "$env:LOCALAPPDATA\webmcp-controller\webmcp-host.exe" uninstall. macOS: ~/Library/Application\ Support/webmcp-controller/webmcp-host uninstall. Linux: ~/.local/share/webmcp-controller/webmcp-host uninstall. All downloads (Windows, macOS, Linux; x64 and arm64): releases page.

2. Connect your AI harness

Also listens on the WSL network adapter (not active), so Claude Code running in WSL can reach this Firefox. Pick “Claude Code inside WSL” above for a command that finds the address by itself. The first time, Windows may ask to allow webmcp-host through the firewall: tick Private networks and click Allow. The token still protects it. (With WSL mirrored networking you don’t need this; 127.0.0.1 works as-is.)

AI cursor

A glowing cursor glides to whatever the AI clicks, types into or reads, with a little bubble saying what it’s doing. It’s only a picture: it never takes over your mouse, and it’s left out of screenshots.

Settings

Generated by this add-on. Your harness sends it as Authorization: Bearer …. “New” invalidates the old one immediately.
Change it if another app (or a second Firefox profile) already uses it.
127.0.0.1 = this computer only (recommended). 0.0.0.0 = reachable from your whole network; the token is then all that protects it.
The AI has to pass confirm: true for closing tabs and windows, removing bookmarks, and similar. It’s a speed bump against mistakes, not a security boundary.

Privacy: page content, tabs, bookmarks and history go only to the helper on this computer and from there to the harness you connect. Nothing is sent anywhere else. Settings stay in this Firefox profile.
