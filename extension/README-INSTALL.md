# WebMCP Controller — install notes

The add-on talks to a small helper app over Firefox **native messaging**.
Firefox starts the helper itself; the helper serves MCP on
`http://127.0.0.1:8901/mcp` for your AI harness.

## 1. Install the helper (once per computer)

- **Windows:** in PowerShell or Command Prompt: `powershell -ExecutionPolicy Bypass -c "irm https://github.com/hamb1y/webmcp-controller/releases/latest/download/install.ps1 | iex"`
- **macOS / Linux:** in Terminal: `curl -fsSL https://github.com/hamb1y/webmcp-controller/releases/latest/download/install.sh | sh`

The toolbar popup shows the exact file and command for your system when the
helper is missing. `status` / `uninstall` work the same way.

## 2. Load the add-on

- Development: `about:debugging#/runtime/this-firefox` → **Load Temporary
  Add-on…** → this folder's `manifest.json`.
- Permanent: `bash scripts/pack-extension.sh`, sign the zip at
  [addons.mozilla.org/developers](https://addons.mozilla.org/developers/)
  (**On your own** = unlisted, minutes), then Add-ons Manager → gear →
  **Install Add-on From File**.

## 3. Connect a harness

Toolbar icon → **Copy MCP config** → paste into your harness. The token is
generated by the add-on; Settings lets you copy/regenerate it and change the
port or bind address.

Background console (`about:debugging` → Inspect):

```js
await browser.runtime.sendMessage({ type: 'get-status' });
await browser.runtime.sendMessage({ type: 'set-config', port: 8902, bind: '127.0.0.1' });
await browser.runtime.sendMessage({ type: 'regenerate-token' });
await browser.runtime.sendMessage({ type: 'reconnect' });
```

## Limits

- Content-script ops (`page.snapshot/text/html`, all `act.*`) are blocked
  with `RESTRICTED_PAGE` on `about:*`, `chrome:*`, `moz-extension:*`,
  `view-source:*`, `data:`/`blob:` pages and on `addons.mozilla.org`.
- Flatpak Firefox can't launch native helpers; use the deb/snap/tarball build.
